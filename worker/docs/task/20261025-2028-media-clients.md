## Description

The user wants the media library to be a general, standalone content library. It publishes media to different clients, each through its own URL. tvbox is one independent consumer that references a client URL like any other source, and the two systems share only the admin console.

The work covers:

- media clients (token URLs) and channels (content partitions) in D1;
- `/m/<token>/{v1,cms,live.m3u,a}` served by the Worker;
- removing `/s/<token>/media/*`, the `@media/` placeholder and media publishing from tvbox;
- going live by `publish_state`, with a generation bumped on writes.

Acceptance:

- the library is reachable only through client URLs;
- restricted titles are hidden from clients outside their channels;
- tvbox has no media code path left;
- `bun run check` and `bun run test:workers` pass.
